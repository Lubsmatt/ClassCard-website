Data and privacy

Learner names, photos and marks stay on this computer. ClassCard never uploads them.

Password protection: Off

With a password on, the data saved on this computer is encrypted and ClassCard asks for the password when you open it. If you forget it, the data cannot be recovered, so keep a backup file.

Password protection needs a current version of Chrome, Edge, Firefox or Safari.

Backups and reset

Back up all classes to a file, or move your data to another computer.

Starting your own school clears the sample learners and keeps nothing. Erase all data removes everything saved in this browser.

Import marks from a spreadsheet

Choose an .xlsx or .csv file. Put learner names in one column and one column per subject. A heading row helps ClassCard match the subjects. You check everything before it is added.
